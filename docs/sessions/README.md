# Session records

One short file per working session that changed a lot: what was asked, what was decided, what was built, how it was checked, and what is still open. They are a record, not the source of truth: decisions live in the phase files' Decisions tables, and the state of the work lives in each phase file's "Start here" and in [`phases/README.md`](../../phases/README.md). A session record points to those; it doesn't repeat them.

Name: `YYYY-MM-DD-what-it-was.md`. Write it before the session ends (AGENTS.md → "Notes live in the repo").
